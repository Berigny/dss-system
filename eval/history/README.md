# DSS-EVAL Claims Registry History

This directory archives historical versions of the DSS-EVAL claims registry.
Each snapshot is named `claims-registry-YYYY-MM-DD.yaml` and reflects the set
of public claims and thresholds that were enforced at that point in time.

When the registry changes, copy the current registry here with a new date stamp
so that previous benchmark releases remain reproducible against the registry
version that was active when they were published.
